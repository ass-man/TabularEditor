# Implement Feature

Use when implementing an approved feature plan.

## Must Do

- Read `AGENTS.md`, `docs/agents/00-start-here.md`, `docs/agents/01-repo-map.md`, `docs/agents/03-build-and-test.md`, and feature `plan.md`.
- Follow `plan.md`.
- Keep changes narrow and reviewable.
- Update or add relevant tests when possible.
- Run relevant validation when possible.
- Update `implementation-log.md` with discoveries, changed files, validation, and next steps.

## Must Not Do

- Do not expand scope without updating the plan.
- Do not do broad refactors.
- Do not touch installer/signing/release/generated files unless plan explicitly requires it.
- Do not claim validation passed unless run.
