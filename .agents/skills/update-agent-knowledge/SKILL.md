# Update Agent Knowledge

Use after a feature or investigation teaches durable repo knowledge.

## Must Do

- Update docs only when knowledge is verified and reusable.
- Prefer concise file/class/method pointers over long explanations.
- Mark uncertain knowledge as uncertain or leave it out.
- Remove stale notes when new verified facts replace them.

## Allowed Files

- `docs/agents/01-repo-map.md`
- `docs/agents/02-architecture-notes.md`
- `docs/agents/04-change-patterns.md`
- `docs/agents/05-common-pitfalls.md`

## Must Not Do

- Do not add one-off feature trivia.
- Do not invent architecture details.
- Do not update product docs unless explicitly asked.
