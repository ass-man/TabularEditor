# Architecture Plan

Use when requirements are known and a self-contained plan is needed.

## Must Read

- `AGENTS.md`
- `PLANS.md`
- `docs/agents/00-start-here.md`
- `docs/agents/01-repo-map.md`
- `docs/agents/03-build-and-test.md`
- Feature `request.md` and `questions.md`

## Must Do

- Inspect only relevant repo areas.
- Produce feature `plan.md` using `PLANS.md` sections.
- Name likely files, classes, methods, tests, risks, and validation.
- Mark uncertain facts as uncertain.
- Make plan self-contained for fresh Codex session.

## Must Not Do

- Do not write production code.
- Do not broaden scope beyond request.
- Do not claim commands work unless verified.
