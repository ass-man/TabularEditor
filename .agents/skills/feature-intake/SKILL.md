# Feature Intake

Use when user has rough feature idea and requirements need clarification.

## Must Do

- Read `AGENTS.md` and `docs/agents/00-start-here.md`.
- Create or update feature folder under `docs/agents/features/<feature-slug>/`.
- Produce `request.md` and `questions.md`.
- Ask focused questions about user-visible workflow, acceptance criteria, constraints, compatibility, and validation.
- Record assumptions clearly when user does not answer.

## Must Not Do

- Do not write code.
- Do not plan implementation details beyond what is needed to clarify requirements.
- Do not scan whole repo.

## Output

- `request.md`: goal, workflow, acceptance criteria, constraints.
- `questions.md`: questions, answers, assumptions, unresolved items.
